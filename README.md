# Daraz Partner Bangladesh — Independent UI Demo v2

A responsive, front-end-only portfolio concept using a black background, white text, orange accents and orange glow effects.

## Files
- `index.html` — page structure
- `style.css` — styling and responsive layouts
- `app.js` — demo-only interactions

## Run locally
Open this folder in VS Code and launch `index.html` with the Live Server extension, or open the file in a browser.

## Demo behavior
- Login/register tabs show one selected form at a time.
- Product showcase is on the home page.
- Orders are in a separate bottom-navigation tab. Each category contains 15 sample orders; only the next incomplete order can be opened until it is completed.
- Reports scroll vertically and are clearly labeled as fictional samples.
- bKash and Nagad are side-by-side demo payment-method cards. Do not send money or enter PINs/OTPs.
- Task toggles are local preview controls, not a secure remote admin system.
- Login, wallet, tasks, points and reports are not connected to a backend. No real payments or withdrawals occur.
